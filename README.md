# Thắp Hương

Trải nghiệm thắp hương trực tuyến được thiết kế cho màn hình điện thoại.

## Development

```bash
npm install
npm run dev
```

## GitHub Pages

Để build và publish phiên bản mới lên nhánh `gh-pages`:

```bash
npm run deploy
```

Trong repository settings, chọn **Pages → Deploy from a branch → `gh-pages` → `/ (root)`**.
